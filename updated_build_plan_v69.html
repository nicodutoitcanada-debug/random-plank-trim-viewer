Prepare the file before importing:
Remove dimensions, text, furniture, hatching, title blocks, symbols and other unnecessary drawing elements. Keep only the wall centerlines you want BUILD PLAN to use. Simple straight lines, connected polylines and basic curves/arcs work best.
